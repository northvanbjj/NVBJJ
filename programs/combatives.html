Gracie Combatives

Adults · Beginners Start Here

Gracie Combatives is our beginner program for adults. We believe this is the best entry point in the world to learn and master the art of Brazilian or Gracie Jiu Jitsu. In this program, you will learn the 36 core techniques of Gracie Jiu-Jitsu in a fun, safe, and educational environment.

Each one-hour lesson addresses one standing and one ground self-defense technique, which are further broken down into technical drills to facilitate the learning process. At the end of each class a realistic reflex development combination sequence will be practiced, performed with varying degrees of intensity, subject to the level you have attained.

You can start the program at any time and participate in any class without previous experience. Since safety and practical skill acquisition is our number one concern, there is a clear focus on the realistic practice of each technique.

  • 36 core self-defense techniques
  • One standing + one ground technique per class
  • Technical drills and reflex development
  • Safe, structured learning for total beginners
